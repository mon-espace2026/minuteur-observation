# Minuteur d’observation

Minuteur d’observation en classe avec plages de deux minutes, pause et reprise. Le calcul et la sauvegarde de la séance sont effectués dans le navigateur.

Application : https://mon-espace2026.github.io/minuteur-observation/

Gardez la page visible et l’écran allumé pendant l’observation. Une séance en cours récupérée après rechargement inclut le temps de fermeture; utilisez Pause pour interrompre le chronométrage. Le maintien automatique de l’écran dépend du navigateur et de l’appareil. Le fonctionnement sur iPhone reste à vérifier sur l’appareil.

Aucune dépendance ni étape de compilation. GitHub Pages sert les fichiers depuis la racine de la branche main.
